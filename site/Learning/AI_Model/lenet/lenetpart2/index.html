    1. Kiến trúc LeNet-5

    LeNet-5 là mạng CNN cổ điển cho bài toán nhận dạng chữ số viết tay (MNIST). Cấu trúc gồm: - 2 lớp tích chập (Conv2d) + Pooling - 3 lớp Fully Connected

    Giải thích từng lớp trong code:

    class SimpleNN(nn.Module):
    def __init__(self):
        super(LeNet5, self).__init__()
        # Lớp Conv1: 1 input channel, 6 output channels, kernel 5x5
        self.conv1 = nn.Conv2d(1, 6, 5)  
        # AvgPool1: Kernel 2x2, stride 2
        self.pool1 = nn.AvgPool2d(2, 2)   
        # Lớp Conv2: 6 input channels, 16 output channels
        self.conv2 = nn.Conv2d(6, 16, 5) 
        self.pool2 = nn.AvgPool2d(2, 2)
        # Lớp Fully Connected
        self.fc1 = nn.Linear(16*5*5, 120)  
        self.fc2 = nn.Linear(120, 84)
        self.fc3 = nn.Linear(84, 10)

    def forward(self, x):
        x = self.pool1(torch.relu(self.conv1(x)))  # Output shape: (6, 14, 14)
        x = self.pool2(torch.relu(self.conv2(x)))  # Output shape: (16, 5, 5)
        x = x.view(-1, 16*5*5)  # Flatten
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        x = self.fc3(x)
        return x

    Giải thích chi tiết:

    • Conv2d: Áp dụng phép tích chập để trích xuất đặc trưng. Ví dụ:

    • nn.Conv2d(1, 6, 5) xử lý ảnh đầu vào 1 kênh (grayscale), tạo 6 feature maps với kernel 5x5.

    • AvgPool2d: Giảm kích thước không gian, tránh overfitting.

    • Linear: Kết nối đầy đủ để ánh xạ đặc trưng thành đầu ra.

    2. Early Stopping: Tránh Overfitting

    Logic chi tiết:

    class EarlyStopping:
    def __call__(self, val_loss, model):
        if self.best_score is None:  # Epoch đầu tiên
            self.best_score = val_loss
            self.best_model_state = model.state_dict()
        elif val_loss < self.best_score - self.delta:  # Cải thiện
            self.best_score = val_loss
            self.counter = 0
            self.best_model_state = model.state_dict()
        else:  # Không cải thiện
            self.counter += 1
            if self.counter >= self.patience:
                self.early_stop = True

    Ví dụ sử dụng: 

    early_stopping = EarlyStopping(patience=5, delta=0.001)

for epoch in range(100):
    # Training và validation...
    val_loss = validate_model(...)
    early_stopping(val_loss, model)

    if early_stopping.early_stop:
        print("Dừng sớm do loss không giảm sau 5 epoch")
        early_stopping.load_best_model(model)  # Khôi phục model tốt nhất
        break

    3. Learning Rate Scheduler: Tối ưu tốc độ học

    ReduceLROnPlateau hoạt động thế nào?

    • Bước 1: Theo dõi validation loss.

    • Bước 2: Nếu loss không giảm sau patience epoch, giảm LR: new_lr = lr * factor

    • Bước 3: Áp dụng LR mới cho optimizer.

    Ví dụ: - Ban đầu: lr = 0.01 - Sau 5 epoch không cải thiện: lr = 0.01 * 0.1 = 0.001

    4. Hàm train_model và validate_model: Giải thích từng bước

    Hàm train_model:

    def train_model(...):
    model.train()  # Chế độ training (kích hoạt Dropout/BatchNorm)
    for inputs, targets in dataloader:
        optimizer.zero_grad()  # Reset gradient từ batch trước
        outputs = model(inputs)  # Forward pass
        loss = criterion(outputs, targets)  # Tính loss
        loss.backward()  # Backpropagation (tính gradient)
        optimizer.step()  # Cập nhật weights

    Hàm validate_model:

    def validate_model(...):
    model.eval()  # Chế độ evaluation (tắt Dropout/BatchNorm)
    with torch.no_grad():  # Không tính gradient để tiết kiệm bộ nhớ
        outputs = model(inputs)
        loss = criterion(outputs, targets)

    5. Độ đo đánh giá: Khi nào dùng Precision, Recall?

    Ví dụ thực tế:

    • Bài toán chẩn đoán bệnh:
    • Precision quan trọng: Tránh dương tính giả (FP) → Không muốn bệnh nhân khỏe bị chẩn đoán mắc bệnh.
    • Recall quan trọng: Tránh âm tính giả (FN) → Không muốn bệnh nhân bệnh bị bỏ sót.

    Bảng so sánh:

    Độ đo Ưu điểm Nhược điểm
    Accuracy Đơn giản, tổng quát Không tốt khi dữ liệu mất cân bằng
    Precision Tập trung vào FP Bỏ qua FN
    Recall Tập trung vào FN Bỏ qua FP
    F1-score Cân bằng Precision và Recall Phức tạp hơn

    b. Training Loop

    for epoch in range(num_epochs):
    # Training phase
    model.train()
    for data, target in train_loader:
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()

    # Validation phase
    model.eval()
    with torch.no_grad():
        for data, target in val_loader:
            output = model(data)
            val_loss += criterion(output, target).item()

    # Early Stopping check
    early_stopping(val_loss, model)

    c. Đánh giá trên Test set

    correct = 0
total = 0
with torch.no_grad():
    for data, target in test_loader:
        outputs = model(data)
        _, predicted = torch.max(outputs.data, 1)  # Lấy class có xác suất cao nhất
        total += target.size(0)
        correct += (predicted == target).sum().item()

print(f'Accuracy: {100 * correct / total:.2f}%')
